External temperature sensor is DS18B20: DATA GPIO23, VDD now wired to **GPIO22** (was 3V3) so firmware can power-cycle it; GND to GND; OLED stays on 3V3 I2C (SDA GPIO6 / SCL GPIO7). Adapter board has onboard 4.7k pull-up to VCC; 2 m cable. Rationale (2nd user-confirmed incident): after ~8 h the probe latched up — 1-Wire answered but only `timing` (EarlyCompletion) and `bad_data` errors grew in /metrics `sensor_errors_by_kind` (`no_presence`/`crc`/`power`/`sensor_reset` stayed 0); ESP32 RST did NOT fix it, only removing board power did. Fix: `src/ds18b20.rs` `Ds18b20::new(data_flex, vdd_output)` with `power_off()` (DATA low first, then VDD low) / `power_on()` / `release_data()`; `src/sensor_recovery.rs` (pure, host-tested): a 5 s window without a valid read starts a ladder — VDD off 1 s / 3 s / 10 s, each followed by a 6 s wait for a valid read; all 3 failing (~32 s) raises `sensor_error`, then a 3 s power cycle every 60 s while faulted. During the ladder `HeaterControl::sensor_resetting()` cuts the heater WITHOUT a fault (resumes after 3 good windows); OLED line 3 shows `Sensor reset n/3`; /api/status `sensor:"resetting"`, `sensor_reset_attempt`, `sensor_power_cycles`; metrics `sensor_resetting`, `sensor_power_cycles_total`, `sensor_recoveries_total`. User explicitly asked: no fault display while resetting, fault only if still unusable after the reset. If VCC is left on 3V3 the firmware works but resets cannot help. `src/bin/ds18b20_serial.rs` also powers the probe from GPIO22. Wiring doc: README.md "DS18B20 wiring and probe power reset" (shield to GND at adapter/ESP32 end only, probe-end 0.1 uF(+10 uF) VDD-GND and 100 ohm in series with DATA, cable 10-15 cm from mains). Committed and pushed to origin/main; the user flashes the firmware themselves, so on-hardware verification is still pending (user must first move the probe VCC wire from 3V3 to GPIO22; README "Checking the wiring after the change" has the pull-VCC / pull-DATA tests). Control platform: Home Assistant or another IoT platform is fine (Xiaomi Home not required); MVP is phone control of a 15–30 °C target plus OLED display; no heater actuator specified.
