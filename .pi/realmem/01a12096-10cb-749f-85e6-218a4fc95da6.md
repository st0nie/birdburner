For the confirmed ESP32-C6 16 MB board: build main ELF with `cargo build --release --locked --bin birdburner`; generate merged image using `espflash save-image --chip esp32c6 --flash-size 16mb --merge --skip-padding target/riscv32imac-unknown-none-elf/release/birdburner FILE.bin`. Flash merged bin at 0x0 (`espflash write-bin`), or flash ELF with `espflash flash --chip esp32c6 --flash-size 16mb`. Full 16MB padding or whole-chip erase would overwrite saved settings at 0xFF0000/0xFF1000. Default partition: factory offset0x10000 size0xFA0000 ends0xFB0000. Mac ports /dev/cu.usbserial-* or /dev/cu.usbmodem*; physical BOOT+RESET may be needed and release BOOT then RESET after flash. Physically disconnect heater mains during flashing because desired_enabled is restored. Firmware embeds configured Wi-Fi credentials; keep artifacts private. Grafana updater `tools/update_grafana.py` transforms API snapshot to version-checked POST payload, preserves existing panels, adds Kp/Ki/Kd/Tf stats and histories, +1C guard on raw temperature, output-held metric. Grafana dashboard backups saved under target/grafana-backup; API credentials must not be stored in script.
